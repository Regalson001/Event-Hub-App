# Event Hub 📅

An interactive, semantically structured web application showcasing upcoming tech events and past conferences, built during my frontend software development training.

## 🚀 Features

* **Semantic HTML Structure:** Built using modern HTML5 standard tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`) for clean document architecture, accessibility, and SEO optimization.
* **In-Page Jump Navigation:** Integrated anchor navigation links within the header allowing users to smoothly jump between `#upcoming-events` and `#past-events`.
* **Structured Event Cards:** Clean presentation of upcoming tech summits and workshops using organized `<article>` components.
* **Past Events Gallery:** Detailed event summaries paired with descriptive images and accessible `alt` text.
